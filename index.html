Aturan pembaruan

Sistem menggunakan aturan yang aman agar record berbeda tidak tertimpa hanya karena satu kolomnya kebetulan sama.

Duplikat persis: hanya jika seluruh kolom pada file dan nilainya sama. Satu kolom sama saja tidak dianggap duplikat.

1. Data baru
Record yang belum ada akan ditambahkan.

2. Data yang cocok
Record diperbarui hanya berdasarkan kolom identitas yang lo pilih.

3. Duplikat persis
Baris yang sama persis di file atau sudah ada di database akan dilewati.

4. Data lama
Record yang tidak muncul di file terbaru tidak akan dihapus.

5. Kunci ambigu
Kalau satu kunci menunjuk ke beberapa record, import dihentikan sampai kunci diperbaiki.
